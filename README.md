## 📦 Install

**One command (installs the whole collection):**

```bash
curl -fsSL https://raw.githubusercontent.com/milad-ahmd/agent-skills/main/install.sh | bash -s -- youtube-seo-optimizer
```

**Manually (Claude Code):**

```bash
git clone https://github.com/milad-ahmd/youtube-seo-optimizer /tmp/youtube-seo-optimizer
mkdir -p ~/.claude/skills && cp -r /tmp/youtube-seo-optimizer/skills/youtube-seo-optimizer ~/.claude/skills/
```

**Per project:** copy `skills/youtube-seo-optimizer` into `<project>/.claude/skills/`.
**Any other agent:** paste [`SKILL.md`](skills/youtube-seo-optimizer/SKILL.md) into your rules or system prompt.
